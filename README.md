## 🚀 Featured Projects

### 🔹 EasyCRUD: Dockerized CI/CD Pipeline on AWS
A full-stack CRUD app taken from source code to an automated deployment.

- **Pipeline:** Jenkins on an AWS EC2 instance builds the frontend and backend images and pushes them to Docker Hub
- **Runtime:** Frontend and backend run as separate Docker containers, connected to a database on **AWS RDS**
- **Stack:** `Jenkins` `Docker` `Docker Hub` `AWS EC2` `AWS RDS` `MariaDB`
- 📂 [View repository](https://github.com/lukademohseen3548-stack/EasyCRUD-Updated)
